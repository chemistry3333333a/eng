# 관리자 도구: 비밀번호 바꾸기

비밀번호를 잊은 사람이 있으면, 관리자 컴퓨터에서 새 비밀번호로 바꿔 줘요.

## 처음 한 번만
1. [Firebase 준비하기 7단계](../docs/firebase-setup.md#7-관리자용-비밀번호-바꾸기-키-받기)대로 키를 받아 `admin/service-account.json` 으로 저장해요.
2. Node.js 22 이상이 필요해요. 이 폴더에서 한 번 설치해요:

```bash
cd admin
npm install
```

## 비밀번호 바꾸기
저장소 맨 위 폴더에서:

```bash
node admin/reset-password.js mallang123 새비밀번호
```

- 성공하면 `✅ mallang123의 비밀번호를 바꿨어요`
- 아이디가 없으면 `❌ 그런 아이디가 없어요`
- 새 비밀번호는 6자 이상이어야 해요. 바꾼 비밀번호는 본인에게 직접 알려 주세요.

## ⚠️ 주의
- `service-account.json` 은 모든 계정을 바꿀 수 있는 열쇠예요. **누구에게도 보내지 말고, 깃허브에 올리지 마세요.** (`.gitignore` 로 막아 두었어요.)
- 키가 새어 나갔다면 Firebase 콘솔 › 프로젝트 설정 › 서비스 계정에서 그 키를 바로 삭제하세요.
