# 마을 꾸미기 설계

날짜: 2026-11-13
시안: `.superpowers/mock/village-3d.html` (버리는 프로토타입, 그림 수준의 기준)

## 왜 만드나

상점에서 산 것들이 지금은 캐릭터 한 명에게만 쓰여요. 아이가 모은 캐릭터들을 한곳에 모아 두고, 코인과 공부 보상으로 자기만의 동화 마을을 키워 가게 해서 공부를 계속할 이유를 하나 더 줘요.

성공한 모습: 아이가 "내 마을" 을 보여 주고 싶어 하고, 다음 건물을 사려고 코인을 모으고, 레벨이 오르면 선물로 장식이 오는 걸 기다려요.

## 정해진 것 (사용자 결정)

- 상점에 "마을 꾸미기" 가 생겨요.
- 그림체는 시안처럼 **3D 떠 있는 동화 섬**이에요. 로우폴리 집·탑·풍차·나무, 부드러운 그림자, 돌려 보기·확대, 낮/밤, 굴뚝 연기·깃발·풍차 같은 움직임이 있어요. 유아 그림 말고 이 수준이 기준이에요.
- **지금 가진 캐릭터**를 마을에 놓을 수 있어요. 캐릭터는 지금 2D 그림을 종이 인형처럼 세워요 (늘 카메라를 봐요, 진짜 그림자).
- 놓는 방법은 "누르고 → 놓을 곳 누르기" 이고, 캐릭터는 콩콩 뛰어서 이동해요.
- 장식은 **코인으로 사기**와 **공부 보상으로 받기** 둘 다 돼요.
- 꾸민 마을은 저장돼요 (기기와 클라우드).

## 목표 / 안 할 것 / 실패로 보는 것

목표
- 장식을 사고·받고, 섬 위에 놓고·돌리고·옮기고·넣을 수 있어요.
- 가진 캐릭터를 아무나 마을에 놓을 수 있어요 (한 캐릭터는 한 자리).
- 장식마다 영어 단어가 있어서, 누르면 읽어 주고 사기 전에 "영어로 주문하기" 할인을 그대로 써요.

안 할 것 (이번엔)
- 섬 넓히기, 친구 마을 구경, 캐릭터 3D 모델, 캐릭터가 마을을 혼자 돌아다니기.

실패로 보는 것
- 시안보다 그림이 확 떨어져 보이는 것 (평평한 색 상자, 유아 그림).
- 아이 태블릿·폰에서 버벅이거나 배터리가 빨리 닳는 것.
- 마을 때문에 기존 상점·저장이 깨지는 것 (옛 세이브 열기, 다른 기기 덮어쓰기).

## 화면과 흐름

### 상점의 "마을" 탭
- 상점 탭에 🏡 **마을** 탭이 생겨요. 영어 상점(🪙)과 수학 상점(💎) 각각 자기 장식만 보여요.
- 칸에는 장식 그림, 영어 단어, 값 또는 상태(보유 n개 / 🔒 조건 / 🎁 선물 조건)가 보여요.
- 장식을 누르면 위쪽 미리보기 칸에 그 장식이 3D로 천천히 돌아가고 단어를 읽어 줘요.
- 사는 흐름은 지금 아이템과 같아요 (영어 퀴즈 10% 할인, 수학은 계산 문제 할인). 오늘의 특가는 장식에 안 걸어요.
- 아래 바에 늘 **"🏡 마을 꾸미러 가기"** 버튼이 있어요.

### 지도의 마을 버튼 (사용자 결정)
- 지도 아래 버튼 줄에 **🏡 마을** 버튼이 생겨요 (🛍️ 상점 버튼 옆, 영어·수학 지도 둘 다).
- 누르면 마을 화면으로 바로 가요. 이때 ⬅️ 는 지도로 돌아가요.

### 마을 화면 (꽉 찬 화면)
- 위: ⬅️ 나가기(들어온 곳으로: 상점 또는 지도), 제목, 🛍️ 상점 가기, 🌙/☀️ 낮밤 버튼.
- 가운데: 3D 섬. 끌면 돌고, 휠·두 손가락으로 확대해요. 처음엔 천천히 저절로 돌다가 무언가 누르면 멈춰요.
- 아래: 가방(트레이). 탭은 **캐릭터 / 건물 / 장식**. 아직 안 놓은 것만 개수와 함께 보여요.
- 놓기: 가방에서 하나 누르기 → 섬 위에 반투명 미리보기가 따라다녀요 (놓을 수 있으면 초록, 겹치거나 섬 밖이면 빨강) → 놓을 곳 누르기.
- 놓인 것 누르기 → 고른 상태가 되고 작은 버튼이 떠요: **↻ 돌리기**(90°씩, 캐릭터는 없음), **옮기기**(다음에 누른 곳으로), **가방에 넣기**.
- 캐릭터를 옮기면 콩콩 뛰어서 가요. 건물은 짧게 통 튀며 내려앉아요.
- 바꾼 건 바로 저장돼요 (별도 저장 버튼 없음).

### 선물 (보상)
- 일부 장식은 **선물 전용**이에요. 조건(레벨, 보스 트로피, 수학 트로피, 도감 수)을 채우면 공짜로 가방에 들어와요.
- 조건은 따로 이벤트를 걸지 않고, 상점이나 마을을 열 때 확인해서 아직 안 받은 선물을 한꺼번에 줘요. 그때 "🎁 선물이 도착했어요!" 창에 받은 장식을 보여 줘요.
- 첫 마을 방문 선물: 오두막 1, 나무 2, 돌길 6. 빈 섬에서 시작하지 않게 하려고요.

## 저장 데이터

`S.village` 를 새로 둬요. 기존 `S.owned`(캐릭터 아이템)와 섞지 않아요.

```
S.village = {
  own:   {cottage: 1, tree: 3, ...},          // 가진 개수 (산 것 + 받은 것)
  gifts: ['first', 'well', ...],              // 이미 받은 선물 (두 번 안 주게)
  placed: [{k:'d', id:'tree', x:1.5, z:-2, r:0}, {k:'c', id:'cat', x:0, z:1}],
  night: false
}
```

- 놓인 장식 수는 `own` 을 넘지 못해요. 가방 = `own` − 놓인 수.
- 캐릭터는 가진 캐릭터만 놓이고, 같은 캐릭터는 한 번만 놓여요.
- `ensure` 가 빈 값·옛 세이브·사라진 id 를 정리해요. 사라진 장식 id 는 `own` 에 남겨 두고(아이템 쪽과 같은 원칙) 섬에서만 빼요.
- 클라우드 저장은 지금처럼 `S` 통째로 올라가요. 따로 할 일 없어요.

## 놓기 규칙

- 바닥은 0.5 칸 격자예요. 장식마다 차지하는 칸 크기(가로×세로)가 있고, 돌리면 가로·세로가 바뀌어요.
- 섬 가장자리 안쪽에만 놓여요. 겹치면 못 놓아요. 캐릭터는 1칸, 돌길·꽃은 다른 것 위에 겹칠 수 없지만 크기가 작아요.
- 이 계산(칸, 겹침, 섬 안쪽)은 3D 와 떼어 놓아 Node 테스트로 확인해요.

## 기술 선택 (제 판단)

- 3D 는 **three.js** 를 써요. 버전을 고정하고 (시안과 같은 0.160.0) CDN 에서 불러와요. Firebase 도 이미 CDN 이라 같은 방식이에요.
- three.js 는 **마을 탭이나 마을 화면을 처음 열 때만** 불러와요. 공부 화면 로딩은 그대로예요.
- 인터넷이 안 돼서 못 불러오면 "마을은 인터넷이 필요해요" 안내를 보여 주고, 상점의 마을 탭은 이모지 그림으로 사고팔 수는 있게 해요.
- 폰·태블릿 대비: 화면 비율 최대 2배, 작은 화면은 그림자 해상도를 낮춰요, 마을 화면이 안 보일 땐 그리기를 멈춰요.
- 밤에 캐릭터만 너무 밝아 보이지 않게 캐릭터도 빛을 받게 해요 (시안에서 보인 문제).

파일 나누기
- `village-items.js`: 장식 데이터만 (DOM 없음).
- `village.js`: 저장 정리, 사기, 선물, 놓기 규칙 (DOM·three 없음, Node 테스트).
- `village-3d.js`: three.js 장면, 장식 모델, 캐릭터 종이 인형, 미리보기 썸네일 (ES 모듈, 나중에 불러옴).
- `village-screen.js`: 마을 화면과 가방, 누르기 처리.
- `shop.js`: 마을 탭 추가.
- 지도 버튼은 `village-screen.js` 가 상점 버튼처럼 스스로 붙여요.
- `tests/village.test.js`: 저장 정리, 사기·선물, 놓기 규칙.

## 빌더에게 맡기는 것

- 장식 모델 하나하나의 모양과 색 (시안 수준 이상, 같은 화풍).
- 가방·버튼의 크기와 배치 (기존 상점 스타일에 맞추기).
- 칸 크기 숫자, 애니메이션 길이.
