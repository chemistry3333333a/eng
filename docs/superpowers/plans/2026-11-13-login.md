# 아이디·비밀번호 로그인 + 기록 동기화 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 누구나 아이디·비밀번호로 가입·로그인하고, 기록 `S`가 Firebase에 저장돼 어느 기기에서든 이어서 하게 만든다.

**Architecture:** 판단 로직(아이디 검증, 오류 문구, 어느 기록을 쓸지, 옮겨 오기 판단)은 DOM·Firebase 없는 `account.js`에 두고 node로 테스트한다. Firebase 호출은 `cloud.js`가 감싸고, `index.html`의 저장·홈·설정 코드가 둘을 쓴다. 저장은 기기(localStorage)에 즉시, 클라우드에는 화면 전환·떠날 때·최대 30초에 한 번.

**Tech Stack:** 순수 HTML/JS (빌드 없음), Firebase JS SDK 10.14.1 compat (gstatic CDN), Firebase Auth(이메일/비밀번호) + Cloud Firestore, node `--test`, 관리자 스크립트는 `firebase-admin`.

**Spec:** `docs/superpowers/specs/2026-11-13-login-design.md`

## Global Constraints

- 브랜치 `feature/login`, `feature/mallang-character` 끝(`cc1cdb1`)에서 딴다.
- 빌드 도구 없음. 새 파일은 `<script src>`로 붙이고 `window.X = {...}` 패턴을 따른다 (`math-core.js` 참고).
- 아이디: 영문 소문자·숫자 4~12자, 입력은 앞뒤 공백 제거 + 소문자로 바꾼다. 이메일 = `<아이디>@wordisland.local`.
- 비밀번호 6자 이상. 부를 이름 1~10자.
- 로그인 실패는 구분하지 않고 **"아이디나 비밀번호가 맞지 않아요"**.
- 비밀번호 안내 문구: **"비밀번호를 잊으면 관리자에게 말해 주세요"** (가입·로그인 화면). 연락처는 적지 않는다.
- Firestore 문서 `saves/{uid}` = `{data, savedAt, id, updatedAt: serverTimestamp()}`. 규칙: 자기 uid만 읽기·쓰기.
- 기기 캐시 키 `wordisland_save_v1:<uid>` = `{data, savedAt, dirty}`. 옛 키 `wordisland_save_v1`, 처리 후 `wordisland_save_v1:migrated`.
- 클라우드 쓰기: `show()` 화면 전환, 설정 닫기, `pagehide`/`visibilitychange`(hidden) 때, 그 밖엔 `dirty`일 때 최대 30초에 한 번.
- `admin/service-account.json`은 절대 커밋하지 않는다 (공개 저장소).
- 아이에게 보이는 모든 문구는 쉬운 한국어. Firebase 오류 코드가 화면에 나오면 안 된다.
- 테스트: `node --test tests/`.

## Review Focus

1. **시작할 때 인터넷이 없음** — 기기 캐시가 있으면 그걸로 바로 플레이, 없으면 "인터넷 연결을 확인해 주세요"와 다시 시도 버튼. 멈추거나 빈 화면이면 안 된다. → Task 4 Step 5
2. **플레이 직후 30초 안에 앱을 닫음** — 같은 기기에서 다시 열면 방금 기록이 남아 있다 (`pickStart` 기기 우선). → Task 1 테스트
3. **가입·로그인 버튼 연타** — 첫 요청 동안 버튼이 막혀서 계정이 두 번 만들어지거나 오류가 뜨지 않는다. → Task 4 Step 5
4. **아이디에 대문자·공백 (`" Mallang1 "`)** — `mallang1`로 바뀌어 통과, `"말랑"`·`"ab"`는 한국어 오류. → Task 1 테스트
5. **인터넷 없이 로그아웃** — 올라가지 않은 기록이 있으면 로그아웃하지 않고 "인터넷이 연결되면 다시 해 주세요". → Task 5 Step 4
