**Interfaces:**
- Produces (모두 `window.MathCore` 아래):
  - 수 값 `V`: 소수 `{t:'d', h:Int}` (h = 값×100, 예: 0.35 → `{t:'d',h:35}`), 분수 `{t:'f', w:Int, n:Int, d:Int}` (0 ≤ n < d, 약분 안 함).
  - `dec(x:number) → V` (예 `dec(2.7)` → `{t:'d',h:270}`, 반올림 `Math.round(x*100)`), `frac(w,n,d) → V` (n ≥ d 이면 자연수로 올림 정규화).
  - `same(a:V, b:V) → boolean` 값 비교(분수끼리 분모 달라도 교차곱, 소수·분수 섞이면 false).
  - `add(a,b)`, `sub(a,b) → V` (분수는 같은 분모만; 결과 정규화).
  - `text(v:V) → string` 소수는 꼬리 0 없이(`1.1`, `0.15`, `3`), 분수는 `"1 2/5"`/`"2/5"`/`"1"` (테스트·로그용, 화면에 쓰지 않음).
  - `html(v:V, cls?) → string` 화면용. 분수는 `<span class="mf"><span>2</span><span class="md">5</span></span>`, 대분수는 `<span class="mx">1<span class="mf">…</span></span>`. 소수는 `text`.
  - `problemHtml(p) → string` → `"{a} + {b} = ?"` (뺄셈은 `−` U+2212).
  - `distractors(p, n:Int) → V[]` 정답과 값이 다르고 서로 다른 오답 n 개.
  - `hintPlan(p) → Plan` (아래).
  - 문제 `p = {a:V, b:V, op:'+'|'-', ans:V}`.

**Plan 모양**
```js
{ kind:'make'|'down'|'gather'|'take'|'break',
  L:V, R:V,            // 작업대 왼쪽(채우거나 빼는 쪽) / 오른쪽(묶음을 떼어 오는 쪽, 뺄셈은 빼는 수)
  need:V|null,         // 끌어서 옮길 묶음 값
  rest:V|null,         // 묶음을 뗀 뒤 남은 것
  made:V|null,         // 만든 수 (make: L+need, down: L−need)
  unit:Int,            // 소수: 틀 한 칸의 백분의 일 단위(10=막대 틀, 1=작은 칸 틀). 분수: 분모
  name:string,         // "1 만들기 작전", "0.5까지 내려가기", "같은 블록 모으기", "빼내기", "쪼개서 빼기"
  steps:[{say:string(HTML), eq:string(HTML), drag?:true, choices?:V[], answer?:V}] }
```

**kind 정하는 규칙 (스펙 4.5)**
- `+`: 받아올림이 없으면 `gather` (끌기: R 전체를 L 쪽으로 → 답 고르기).
- `+` 받아올림 있음 → `make`.
  - 소수: 받아올림이 생기는 **가장 낮은 자리** p(백분의 일 → unit 1, 십분의 일 → unit 10). L 은 두 수 중 p 아래 자리 숫자가 0 인 쪽을 우선, 둘 다 같으면 p 자리 숫자가 큰 쪽. `need = (10 − L의 p자리 숫자) × unit`(백분의 일 정수). `made = L + need`, `rest = R − need`.
  - 분수: L 은 분수 부분이 큰 쪽, `need = (d − L.n)/d`, `made = L.w + 1`, `rest = R − need`.
  - steps(5개): ① need 고르기 ② drag ③ rest 고르기 ④ made 고르기 ⑤ ans 고르기.
- `−`: 받아내림이 없으면 `take` (끌기: R 만큼 빼내기 → 답 고르기).
- `−` 받아내림 있음:
  - `need` = L 의 "받아내림 자리 아래 조각": 소수는 `L mod 10` 이 0 이 아니면 그것(0.53 → 0.03), 0 이면 `L mod 100`(1.2 → 0.2). 분수는 `L.n/d`.
  - R 에 자연수 부분이 있으면 먼저 그만큼 뺀 L' 로 위 계산(스펙 3 1/5 − 1 3/5 → 첫 단계 "3 1/5 − 1 = ?").
  - `0 < need ≤ R의 나머지` 이면 `down`: steps = [(자연수 빼기 고르기)] + ① need 고르기 ② drag(빼내기) ③ rest 고르기 ④ made 고르기 ⑤ ans 고르기. 마지막 단계에서 판/막대가 쪼개지는 장면(Task 5).
  - 그 밖(need 가 0 이거나 R 보다 큼: 3 − 1.25, 1 − 3/8, 1.9 − 0.35)은 `break`: steps = [(R 자연수 빼기 고르기)] + ① drag(판/막대 하나를 쪼개서 R 의 나머지를 빼내기) ② ans 고르기.
- 단계 보기 3개: answer + 같은 단계의 흔한 실수(자리 틀림 ×10/÷10, 분모 더하기, 1 큰/작은 값)에서 `same` 으로 중복 제거 후 채움. `say`/`eq` 문구는 시안 v8 과 같은 말투("맞아, 0.3이 모자라! …", 아직 맞히지 않은 값은 eq 에서 `?`).
- `name`: make → `${text(made)} 만들기 작전`, down → `${text(made)}까지 내려가기`.

**오답 규칙 (`distractors`)** — 후보를 순서대로 만들고 `same` 중복·정답과 같은 것 제거, 모자라면 정답 ±1단위로 채운다.
- 소수 `+`: 자리 안 맞추기(오른쪽 정렬로 더하기: 0.35+0.8 → 0.43), 받아올림을 아래 자리에 붙여 쓰기(2.7+1.4 → 3.11), 받아올림 빠뜨리기(정답 − 1, 정답 − 0.1).
- 소수 `−`: 큰 숫자에서 작은 숫자 빼기(자리마다 |차|), 받아내림 후 윗자리 안 줄이기(정답 + 0.1, 정답 + 1).
- 분수 `+`: 분모끼리 더하기(n1+n2)/(d+d), 자연수로 안 넘기고 자연수 빼먹기(정답 − 1), 자연수 1 덜 넘기기(정답 − 1/d 등).
- 분수 `−`: 분자 자리 바꿔 빼기(|n1−n2|/d), 받아내림 후 자연수 안 줄이기(정답 + 1).
