# 코인상점 + 캐릭터 꾸미기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 코인으로 꾸미기 아이템을 사서 캐릭터에 입히고, 그 캐릭터가 지도·상점·스테이지·보스전·앵무새탐정·결과 화면에 나오게 한다.

**Architecture:** 데이터(`items.js`)와 캐릭터 로직·그리기(`avatar.js`, `window.Avatar`)를 게임에서 분리한다. 그래서 이후 다른 게임(단어 디펜스)도 `Avatar`만 불러 쓰면 된다. 상점 화면은 `boss.js`처럼 스스로 화면과 CSS를 주입하는 `shop.js`로 만든다. `index.html`과 `boss.js`에는 연결 코드만 넣는다.

**Tech Stack:** 빌드 없는 순수 HTML/CSS/JS. 로직 테스트는 Node 24 내장 `node:test`와 `vm`으로 돌린다(설치할 의존성 없음). 화면은 `.claude/launch.json`의 `word-island` 미리보기(http://localhost:8080)로 확인한다.

**Spec:** `docs/superpowers/specs/2026-10-19-coin-shop-design.md`

## Global Constraints

- 스크립트 로드 순서: `words.js` → `items.js` → `avatar.js` → (index.html 본문 스크립트) → `boss.js` → `shop.js`
- `avatar.js`와 `items.js`는 **불러오는 순간 DOM이나 `S`에 접근하지 않는다.** 전역(`S`, `save`, `today`, `level`, `speak`, `$`)은 함수가 호출될 때만 읽는다. 그래야 Node 테스트에서 불러올 수 있다.
- 저장 키 `wordisland_save_v1`, `S.v = 1`은 그대로 둔다. 기존 필드는 절대 지우거나 바꾸지 않는다.
- 새 저장 필드: `S.avatar = {body:'kid1', equip:{hat:null, face:null, hand:null, back:null, effect:null}}`, `S.owned = []`, `S.shop = {freeGiven:false, dealDay:'', dealId:''}`
- 슬롯: `hat`, `face`, `hand`, `back`, `effect`. 펫은 슬롯이 아니라 기존 `S.petOn`을 쓴다.
- 기본 몸 6종: `kid1` 🧒, `kid2` 👧, `kid3` 👦, `cat` 🐱, `dog` 🐶, `bunny` 🐰. 무료이고 기본값은 `kid1`이다.
- 가격대: 기본 30~60, 중급 100~200, 레어 300~500. 1단계 아이템은 약 24개(슬롯당 4~6개)이고 전체 합계는 4,000~5,000이다.
- `unlock`은 `{level:n}`, `{trophies:n}`, `{dex:n}`, `null` 중 하나다. 각 값의 계산은 다음과 같다.
  - trophies = `Object.values(S.trophies||{}).filter(v => v > 0).length`
  - dex = `Object.values(S.words).filter(st => st.seen > 0).length`
  - level = 기존 `level()`
- 잠금 문구: `레벨 N 필요` / `보스 N마리 물리치기` / `몬스터 N마리 잡기`
- 할인은 겹치지 않는다. 특가는 30%, 영어로 주문하기는 10%다. 특가 아이템에는 퀴즈를 띄우지 않는다. 가격은 `Math.ceil(price * (1 - rate))`로 계산한다.
- perk 태그: `splash`, `slow`, `shield`, `pierce`, `coin`. 기존 게임에서는 게임 효과가 **없다**(외형만).
- 첫 방문 선물 후보는 가격 30 이하 아이템이다.
- UI 문구는 한국어, 아이템 이름은 영어 단어(`word`)다. 아이템 칸을 누르면 `speak(word)`.
- 이 폴더는 git 저장소가 아니다. 그래서 커밋 단계 대신 각 Task 끝에 "중간 점검"을 둔다. 실행 전에 사용자가 `git init`을 원하면 그때 커밋 단계를 되살린다.

## Review Focus

1. **옛 세이브와 옛 백업 코드**(avatar/owned/shop 필드 없음): 오류 없이 기본값으로 채워지고 코인·스테이지·펫은 그대로여야 한다. → Task 2 `ensure` 테스트 + Task 2 Step 6 브라우저 확인

const test = require('node:test'), assert = require('node:assert');
const {load} = require('./load');
const vm = require('vm');
const ctx = load(['items.js']);
const get = n => vm.runInContext(n, ctx);

test('item ids are unique and slots valid', () => {
  const ids = get('ITEMS').map(i => i.id);
  assert.equal(new Set(ids).size, ids.length);
  for (const i of get('ITEMS')) assert.ok(get('SLOTS').includes(i.slot), i.id);
});
test('every item has an English word and a price in 30..500', () => {
  for (const i of get('ITEMS')) {
    assert.match(i.word, /^[a-z][a-z ]*$/, i.id);
    assert.ok(i.price >= 30 && i.price <= 500, i.id);
  }
});
test('about 24 items, 4..6 per slot, total 4000..5000', () => {
  const items = get('ITEMS');
  assert.ok(items.length >= 20 && items.length <= 30);
  for (const s of get('SLOTS')) { const n = items.filter(i => i.slot === s).length; assert.ok(n >= 4 && n <= 6, s); }
  const sum = items.reduce((a, i) => a + i.price, 0);
  assert.ok(sum >= 4000 && sum <= 5000, String(sum));
});
test('at least 3 gift candidates (price <= 30)', () => {
  assert.ok(get('ITEMS').filter(i => i.price <= 30).length >= 3);
});
test('unlock and perk values are from the allowed sets', () => {
  for (const i of get('ITEMS')) {
    if (i.unlock) { const k = Object.keys(i.unlock); assert.equal(k.length, 1, i.id); assert.ok(['level','trophies','dex'].includes(k[0]), i.id); }
    assert.ok(i.perk === null || ['splash','slow','shield','pierce','coin'].includes(i.perk), i.id);
  }
});
test('items priced 300+ are locked', () => {
  for (const i of get('ITEMS')) if (i.price >= 300) assert.ok(i.unlock, i.id);
});
test('6 bodies, first is kid1; PETS has the 11 boss ids', () => {
  assert.deepEqual(get('BODIES').map(b => b.id), ['kid1','kid2','kid3','cat','dog','bunny']);
  assert.deepEqual(Object.keys(get('PETS')).map(Number).sort((a,b)=>a-b), [10,20,30,103,104,105,106,107,108,109,110]);
});

### Task 2: 캐릭터 로직 (`avatar.js` — 구매·장착·잠금·특가·마이그레이션)

**Files:**
- Create: `avatar.js` (이 Task에서는 로직만. 그리기는 Task 3)
- Create: `tests/avatar.test.js`
- Modify: `index.html` — `<script src="avatar.js">`를 items.js 다음에 추가. `freshSave()` 반환값, `renderHome()`의 `S = loadSave()` 직후, `restoreBtn`의 `S = data` 직후에 `Avatar.ensure(S)` 호출

**Interfaces:**
- Consumes: Task 1의 `ITEMS`, `BODIES`, `SLOTS`, `PETS`. 호출 시점의 전역 `S`, `save()`, `today()`, `level()`
- Produces (`window.Avatar`):
  - `ensure(s) -> s`: 빠진 필드를 기본값으로 채운다. `equip`에서 `ITEMS`에 없거나 `owned`에 없는 id는 `null`로, `owned`에서 `ITEMS`에 없는 id는 제거한다. `body`가 `BODIES`에 없으면 `'kid1'`로 바꾼다.
  - `item(id) -> item | undefined`
  - `owns(id) -> boolean`
  - `isUnlocked(item) -> boolean`, `lockText(item) -> string` (풀렸으면 `''`)
  - `deal() -> {id, price} | null`: `S.shop.dealDay !== today()`이거나 `dealId` 아이템이 이미 산 것/잠긴 것이면 새로 고른다(풀렸고 안 산 아이템 중 무작위). 후보가 없으면 `dealId=''`로 두고 `null`을 돌려준다. 바뀌었으면 `save()`
  - `priceOf(id, {quiz=false}={}) -> number`: 특가 아이템이면 `ceil(p*0.7)`(quiz 무시), 아니면 quiz일 때 `ceil(p*0.9)`, 그 외 `p`
  - `canBuy(id, opts) -> {ok:true, price} | {ok:false, reason:'unknown'|'owned'|'locked'|'coins', need?:number}` (`need` = 부족한 코인 수)
  - `buy(id, opts) -> canBuy 결과`: ok일 때만 `S.coins -= price`, `S.owned.push(id)`, `save()`
  - `equip(id) -> boolean` (산 것만 가능, 같은 슬롯은 교체), `unequip(slot)`, `setBody(bodyId) -> boolean`
  - `equipped() -> {hat, face, hand, back, effect}` (복사본)
  - `perks() -> string[]` (장착 아이템의 non-null perk)
  - `giftChoices() -> item[]` (price ≤ 30), `claimGift(id) -> boolean`: `freeGiven`이 false이고 후보일 때만 소유+장착+`freeGiven=true`+`save()`

- [ ] **Step 1: 실패하는 테스트 작성 — `tests/avatar.test.js`**

매 테스트마다 새 컨텍스트를 쓴다: `load(['items.js','avatar.js'], {S, save(){saves++}, today:()=>day, level:()=>lv})`. `S`는 `{coins, stages:{}, words:{}, trophies:{}, pets:[]}`로 만들고 `Avatar.ensure(S)`를 먼저 부른다. 아이템은 하드코딩하지 말고 `ITEMS`에서 조건으로 고른다(예: 잠기지 않은 가장 싼 것 `cheap`, `{level:n}` 잠금이 있는 것 `lockedLv`).

```js
test('ensure fills defaults on an old save and keeps existing fields', () => {
  const S = {name:'민준', coins:50, xp:120, stages:{1:{stars:2}}, words:{}, petOn:10, pets:[10]};
  Avatar.ensure(S);
  assert.deepEqual(S.avatar, {body:'kid1', equip:{hat:null,face:null,hand:null,back:null,effect:null}});
  assert.deepEqual(S.owned, []); assert.deepEqual(S.shop, {freeGiven:false, dealDay:'', dealId:''});
  assert.equal(S.coins, 50); assert.equal(S.petOn, 10); assert.deepEqual(S.stages, {1:{stars:2}});
});
test('ensure drops unknown ids', () => {
  S.owned = ['nope', cheap.id]; S.avatar.equip.hat = 'nope'; S.avatar.body = 'alien';
  Avatar.ensure(S);
  assert.deepEqual(S.owned, [cheap.id]); assert.equal(S.avatar.equip.hat, null); assert.equal(S.avatar.body, 'kid1');
});
test('buy deducts once; buying twice is rejected', () => {
  S.coins = cheap.price * 3;
  assert.equal(Avatar.buy(cheap.id).ok, true);
  assert.deepEqual(Avatar.buy(cheap.id), {ok:false, reason:'owned'});
  assert.equal(S.coins, cheap.price * 2);
});
test('exact coins is enough; one short reports need', () => {
  S.coins = cheap.price - 1;
  assert.deepEqual(Avatar.canBuy(cheap.id), {ok:false, reason:'coins', need:1});
  S.coins = cheap.price; assert.equal(Avatar.buy(cheap.id).ok, true); assert.equal(S.coins, 0);
});
test('locked item cannot be bought; unlocks by level', () => {
  S.coins = 9999; lv = lockedLv.unlock.level - 1;
  assert.equal(Avatar.canBuy(lockedLv.id).reason, 'locked');
  assert.equal(Avatar.lockText(lockedLv), `레벨 ${lockedLv.unlock.level} 필요`);
  lv = lockedLv.unlock.level; assert.equal(Avatar.canBuy(lockedLv.id).ok, true);
});
test('trophies count bosses with stars > 0; dex counts seen words', () => {
  S.trophies = {10:1, 103:0, 104:3}; S.words = {apple:{seen:1}, dog:{seen:0}};
  // 위 상태에서 {trophies:2}는 풀리고 {trophies:3}은 잠김, {dex:1}은 풀리고 {dex:2}는 잠김
  assert.equal(Avatar.isUnlocked({unlock:{trophies:2}}), true);
  assert.equal(Avatar.isUnlocked({unlock:{trophies:3}}), false);
  assert.equal(Avatar.isUnlocked({unlock:{dex:1}}), true);
  assert.equal(Avatar.isUnlocked({unlock:{dex:2}}), false);
  assert.equal(Avatar.lockText({unlock:{trophies:3}}), '보스 3마리 물리치기');
  assert.equal(Avatar.lockText({unlock:{dex:2}}), '몬스터 2마리 잡기');
});
test('quiz gives 10% (ceil); deal gives 30% and ignores quiz', () => {
  const d = Avatar.deal(); const p = Avatar.item(d.id).price;
  assert.equal(d.price, Math.ceil(p * 0.7));
  assert.equal(Avatar.priceOf(d.id, {quiz:true}), Math.ceil(p * 0.7));
  const other = ITEMS.find(i => i.id !== d.id);
  assert.equal(Avatar.priceOf(other.id, {quiz:true}), Math.ceil(other.price * 0.9));
});
test('deal is stable within a day, rerolls next day, skips owned, null when nothing left', () => {
  const a = Avatar.deal(); assert.deepEqual(Avatar.deal(), a);
  S.coins = 99999; Avatar.buy(a.id); assert.notEqual(Avatar.deal()?.id, a.id);
  S.owned = ITEMS.map(i => i.id);   // 전부 소유하면 고를 게 없음
  assert.equal(Avatar.deal(), null);
});
test('equip only owned items; same slot replaces; perks reflect equipment', () => {
  const wand = ITEMS.find(i => i.slot === 'hand' && i.perk);
  assert.equal(Avatar.equip(wand.id), false);
  S.owned.push(wand.id); assert.equal(Avatar.equip(wand.id), true);
  assert.deepEqual(Avatar.perks(), [wand.perk]);
  Avatar.unequip('hand'); assert.deepEqual(Avatar.perks(), []);
});
test('gift: only once, only cheap items, auto-equipped', () => {
  const g = Avatar.giftChoices(); assert.ok(g.every(i => i.price <= 30));
  assert.equal(Avatar.claimGift(g[0].id), true);
  assert.equal(Avatar.equipped()[g[0].slot], g[0].id);
  assert.equal(Avatar.claimGift(g[1].id), false);
});
```
