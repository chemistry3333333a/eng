# 마을 꾸미기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 상점·지도에서 들어가는 3D 동화 마을을 만들어요. 장식은 코인으로 사거나 공부 보상으로 받고, 가진 캐릭터와 함께 섬 위에 놓아요.

**Architecture:** 데이터(`village-items.js`)와 규칙(`village.js`)은 DOM·three 없이 Node 테스트로 확인해요. 3D(`village-3d.js`, ES 모듈)는 처음 쓸 때 `import()` 로 불러와요. 화면(`village-screen.js`)은 boss.js·shop.js 처럼 section 과 버튼을 스스로 붙여요. 상점은 `shop.js` 에 마을 탭만 더해요.

**Tech Stack:** 순수 JS(전역 스크립트), three.js 0.160.0 (jsdelivr ES 모듈, importmap 없이 전체 URL), `node --test tests/`.

**Spec:** `docs/superpowers/specs/2026-11-13-village-design.md`

## Global Constraints

- three.js 는 `https://cdn.jsdelivr.net/npm/three@0.160.0/...` 고정, 마을 탭·마을 화면을 처음 열 때만 불러와요.
- 저장은 `S.village = {own, gifts, placed, night}` 하나. `S.owned` 는 건드리지 않아요.
- 모든 장식은 `cur:'eng'|'math'`, 영어 장식 `word` 는 소문자 영어. 값은 30–500 (stack 장식은 10–60).
- 오늘의 특가는 장식에 걸지 않아요. 영어 퀴즈·수학 문제 10% 할인은 그대로 써요.
- 격자 0.5, 섬 놓기 반지름 `ISLAND_R = 7.2`.
- 화면 글은 한국어, 기존 코드 주석 말투(~해요)를 따라요.

## Review Focus

1. 옛 세이브(`S.village` 없음, 이상한 값) → 새 마을로 정리, 오류 없음. (Task 2 테스트)
2. 놓인 수가 가진 수보다 많은 세이브 → 넘치는 것만 섬에서 빼요. (Task 2 테스트)
3. 캐릭터를 안 가진 세이브(다른 기기에서 날아온 것) → 그 캐릭터만 섬에서 빼요. (Task 2 테스트)
4. 선물 조건을 한 번에 여러 개 채움 → 전부 한 번씩만 들어와요, 다시 열어도 또 안 줘요. (Task 2 테스트)
5. 인터넷이 안 돼 three.js 를 못 불러옴 → 안내 토스트, 상점 마을 탭은 이모지로 사고팔기 됨. (Task 4 브라우저 확인)

### Task 2: 마을 규칙 (저장·사기·선물·놓기)

**Files:**
- Create: `village.js`
- Test: `tests/village.test.js`

**Interfaces:**
- Consumes: `DECOR`, `BODIES`, `Avatar.{owns,isUnlocked,lockText}`, 전역 `S`, `save()`.
- Produces: `window.Village`
  - `ensure(s) -> s` — `s.village` 를 정리 (Review Focus 1–3).
  - `item(id)`, `list(cur) -> DECOR[]`
  - `owned(id) -> number`, `bag() -> [{k:'d'|'c', id, n}]` (안 놓은 것; 캐릭터는 가진 것 중 안 놓인 것)
  - `canBuy(id, opts) -> {ok, price, reason:'locked'|'coins'|'owned'|'giftOnly', need}` — stack 아니면 1개까지
  - `priceOf(id, {quiz})`, `buy(id, opts) -> canBuy 결과` (지갑은 cur 따라 `S.coins` / `S.math.coins`)
  - `claimGifts() -> [{id, n}]` — 조건 채운 안 받은 선물을 넣고 `gifts` 에 기록. 받을 게 없으면 `[]`.
  - `cells(entry) -> [[cx,cz],...]`, `canPlace(entry, ignoreIndex) -> boolean`
  - `place({k,id,x,z,r}) -> index|-1`, `move(index, x, z) -> boolean`, `rotate(index) -> boolean`, `remove(index)`
  - `setNight(bool)`
  - `ISLAND_R = 7.2`, `snap(v) -> v` (0.5 격자)

- [ ] **Step 1: 실패하는 테스트** (avatar.test.js 의 `mk()` 처럼 `items.js, avatar-art.js, avatar.js, village-items.js, village.js` 를 로드)

```js
test('ensure: missing/garbage village becomes empty', () => {
  const {S, V} = mk(); S.village = 'x'; V.ensure(S);
  assert.deepEqual(S.village, {own:{}, gifts:[], placed:[], night:false});
});
test('ensure: drops overflow placed decor and unowned characters', () => {
  const {S, V} = mk();
  S.village = {own:{tree:1}, gifts:[], placed:[{k:'d',id:'tree',x:0,z:0,r:0},{k:'d',id:'tree',x:2,z:0,r:0},{k:'c',id:'unicorn',x:3,z:3},{k:'c',id:'cat',x:-3,z:0}], night:false};
  V.ensure(S);
  assert.deepEqual(S.village.placed.map(p => p.id), ['tree','cat']);
});
test('buy: coins, stack, one-only, gift-only, locked', () => {
  const {S, V} = mk(); S.coins = 1000;
  assert.equal(V.buy('tree').ok, true); assert.equal(V.buy('tree').ok, true); assert.equal(V.owned('tree'), 2);
  assert.equal(V.buy('house').ok, true); assert.equal(V.canBuy('house').reason, 'owned');
  assert.equal(V.canBuy('windmill').reason, 'giftOnly');
  assert.equal(V.canBuy('castle').reason, 'locked');
  assert.equal(S.coins, 1000 - 40 - 40 - 220);
});
test('buy math decor spends gems', () => { const {S, V} = mk(); S.math.coins = 250; assert.equal(V.buy('fountain').ok, true); assert.equal(S.math.coins, 50); });
test('claimGifts: first visit once, level gifts once', () => {
  const {S, V, env} = mk();
  assert.deepEqual(V.claimGifts().map(g => g.id).sort(), ['cottage','path','tree']);
  assert.equal(V.owned('path'), 6); assert.deepEqual(V.claimGifts(), []);
  env.lv = 10; assert.deepEqual(V.claimGifts().map(g => g.id).sort(), ['well','windmill']); assert.deepEqual(V.claimGifts(), []);
});
test('place: inside island, no overlap, needs stock', () => {
  const {S, V} = mk(); S.village.own = {tree:1, house:1};
  assert.ok(V.place({k:'d', id:'house', x:0, z:0, r:0}) >= 0);
  assert.equal(V.place({k:'d', id:'tree', x:0.5, z:0, r:0}), -1);   // 겹침
  assert.equal(V.place({k:'d', id:'tree', x:9, z:0, r:0}), -1);     // 섬 밖
  assert.ok(V.place({k:'d', id:'tree', x:4, z:0, r:0}) >= 0);
  assert.equal(V.place({k:'d', id:'tree', x:-4, z:0, r:0}), -1);    // 재고 없음
});
test('characters: owned only, once each; rotate swaps footprint; remove returns to bag', () => {
  const {S, V} = mk(); S.village.own = {bench:1};
  assert.ok(V.place({k:'c', id:'cat', x:2, z:2}) >= 0);
  assert.equal(V.place({k:'c', id:'cat', x:-2, z:2}), -1);
  assert.equal(V.place({k:'c', id:'unicorn', x:-2, z:-2}), -1);
  const i = V.place({k:'d', id:'bench', x:-3, z:0, r:0});
  assert.equal(V.rotate(i), true); assert.equal(S.village.placed[i].r, 1);
  V.remove(i); assert.ok(V.bag().some(b => b.id === 'bench' && b.n === 1));
});
```
